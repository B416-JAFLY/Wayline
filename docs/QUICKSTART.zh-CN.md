# Omdrop 快速开始

Omdrop 通过 USB 连接的 M5Stack Cardputer Adv，在 Windows 与 Apple 设备之间收发 AirDrop 文件。
需要 Windows 10/11 x64、支持蓝牙 LE 广播的电脑，以及一根能传输数据的 USB 线。

## 安装

下面介绍默认桌面安装包。将完整离线安装包解压到本地目录，双击 `install.cmd`，按 Windows 提示允许安装后台服务。
安装完成后会以普通用户身份打开 Omdrop。请不要以管理员身份运行桌面，否则资源管理器拖放可能不可用。
安装包已经包含固件和烧录工具，安装与烧录无需 Rust、Python、ESP-IDF 或联网下载。

覆盖更新前，先完成传输，从托盘退出 Omdrop，并结束正在运行的 CLI 命令。
安装器先核对全部文件和校验值，再替换程序；旧程序保存在安装目录旁的备份目录。
收到的文件、用户名称和身份配置保存在程序目录之外，不会因覆盖更新而删除。

## 初始化 Cardputer Adv

1. 使用数据线连接 Cardputer Adv，点击分享卡片顶部的“设备固件”。
2. 选择设备对应的串口，并明确确认板型是 Cardputer Adv。多个设备同时连接时，请仔细核对端口。
3. 首次安装选择“首次 / 重新安装”。它会替换原程序和分区布局，不保证保留其他固件的数据。
4. 已安装 Omdrop 的设备可选择“保留设置更新”。仅在原固件可识别且分区布局一致时允许继续。
5. 点击底部的“开始安装”或“开始更新”，等待写入、校验、启动检查全部结束，界面显示“设备已就绪”。

安装期间不要拔线。关闭分享卡片只隐藏界面，安装仍会继续；从托盘退出会询问是否取消。
写入开始后的取消或断电可能需要完整重刷，不支持自动回滚。

未发现设备时检查数据线，点击刷新。必要时按住 G0，再点按 RST 进入下载模式。
写入完成但启动失败时，松开 G0 再点按 RST，保持设备连接后重试。
端口被占用时，结束其他 CLI 传输、串口监视器或烧录软件后再试。

## 收发文件

电脑打开蓝牙；iPhone 打开 Wi-Fi 和蓝牙，并将 AirDrop 设置为“所有人（10 分钟）”。
电脑无需连接同一个路由器，内置 Wi-Fi 也无需开启。

- 发送：拖入文件，或通过托盘、`Ctrl+O`、文件右键“通过 Omdrop 发送”选取文件，再选择接收设备。
- 接收：在 Apple 设备的 AirDrop 列表选择这台电脑，在 Omdrop 确认卡片上接受。文件保存到下载目录中的 `Omdrop` 文件夹。
- 设备名称：在分享卡片设置中修改，CLI 与桌面使用同一名称与身份。
- 上传到 100% 后仍需等待接收端最终确认；只有“已送达”才代表发送成功。

右上角 × 或 Esc 隐藏卡片，接收继续运行。托盘“退出”结束本客户端的任务；若 CLI 仍在使用无线，后台会继续运行。
默认按需服务在最后一个客户端退出后回收无线设备；独立服务部署可以常驻。

## 可选命令行工具

独立 CLI 工具包解压后可直接在 PowerShell 中运行 `./omdrop-cli.exe --help`，无需安装。
无线收发需要先安装桌面包或独立后台服务包；独立后台服务包用 `install.cmd` 安装，后台常驻且不打开界面。

```powershell
./omdrop-cli.exe status --json
./omdrop-cli.exe discover
./omdrop-cli.exe send --to "iPhone" -- "C:\Users\Example\Pictures\photo.jpg"
./omdrop-cli.exe receive
```

接收默认逐次询问。脚本无人值守接收必须明确添加 `--accept-all`；Ctrl+C 结束命令并释放自己的无线会话。
完整参数、JSON 输出与退出码见源码仓库的 `docs/DEVELOPMENT.md`。
